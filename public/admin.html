Module Dashboard

Add or update slide modules here. Saved modules appear on the public homepage automatically—no need to edit the website code for every new module.

One-time setup required

Before signing in, paste your Firebase web app configuration into the firebaseConfig object in both index.html and admin.html. Then enable Email/Password in Firebase Authentication and create your own admin user there. Never put your password in source code.

Admin sign in

Only the single admin email configured in Firestore rules should be authorized. The login page is not linked from the public homepage, but security comes from authentication and database rules—not from hiding the URL.
